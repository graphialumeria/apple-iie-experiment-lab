Click the screen, then type. Enter, Backspace, Escape, arrow keys, and Ctrl + letter work too. The text demo echoes a wrapping line. Play colors + music boots an original ROM; its melody uses the built-in speaker. Pause to inspect registers or step through the running code.

Load your own 6502 experiment

Hex bytes are loaded into main RAM and execution starts at your address. Default example writes an A into the upper-left text cell and loops. Use Text demo first for a clean machine state.

ROM / BOOT

Load a 16 KB combined ROM mapped at $C000, or 12 KB at $D000. The original Color / Pulse ROM is built in. External images must use original-IIe 6502 instructions; Apple ROMs are not included.

Running the built-in RAM demo.

Experimental implementation: no disk controller, joystick, MouseText, double hi-res, or 65C02 extensions. Hi-res uses a monochrome approximation. Apple firmware boot compatibility is unverified. Color / Pulse is tested in this emulator.
